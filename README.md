# Android Cloud Emulator

Proyek ini menyediakan konfigurasi Android Emulator di GitHub Codespaces dan GitHub Actions.

## ✅ Fitur

- Android Emulator di container
- CI/CD Android UI Test
- Bisa digunakan langsung di Codespaces

## 🚀 Menjalankan di Codespaces

1. Buka repositori di GitHub.
2. Klik **Code > Open with Codespaces**.
3. Setelah container siap, jalankan:

```bash
.devcontainer/start-emulator.sh
